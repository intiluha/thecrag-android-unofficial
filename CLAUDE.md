The goal is to implement FOSS app for https://www.thecrag.com, that uses the same API as the web UI.
Stage 1: no auth, online guide - navidate crags, list routes, see topos, show locations on map.
Stage 2: auth, logbook, ticking ascents.
Stage 3: offline storage of favourite crags, with topos.
Out-of-scope: adding/editing routes/crags/topos.
